## B. 필수 절

| 절 | 제목 | 반드시 포함 |
|---|---|---|
| 1 | 문서 범위와 읽는 방법 | 상태 라벨 정의. "필요 항목"은 요청할 항목이지 실제 컬럼이 아님 |
| 2 | 먼저 확보할 핵심 묶음 | 우선순위 표(묶음 / 답하려는 질문). 핵심 관문 4개: 전체 독립 점포, 입점 이력, 공실 조건, 입점 예정 |
| 3 | 목록의 직접 활용 데이터 | 나이스(D-01~06), 통신·카드·소득(D-07~11), 대구로(D-12~17) 표. 열: 데이터명 / 기간 / 용도 / 필요 항목·확인 사항 / **근거(카드 ID)** |
| 4 | 조건부 보완 데이터 | D-18~34. 각 행에 한계와 주의점 |
| 5 | 안심구역에 추가 요청할 데이터 | **보유가 확인된 목록이 아님**을 명시. 우선순위 / 데이터 / 원하는 항목 / 목적 |
| 6 | 문의처별 문의 내용 | Q-01~06. "문의 경로 제안"임을 명시 |
| 7 | 안심구역 밖에서 확보할 자료 | 공실, 시설·임대료, 입점 예정, 메뉴·가격, 실적, 미충족 수요. 공실 자료가 없을 때의 결과물 축소 |
| 8 | 기간·지역별 분석 조합 | 분석안 / 묶을 자료 / 공통 기간 / 유의점. 공통 기간은 계산으로 검증 |
| 9 | 결합용 최소 데이터 구조 | 점포 이력, 소비 집계, 유동인구, 공실 조건, 입점 예정, 운영 결과 |
| 10 | 문의 시 바로 확인할 질문 | 8~10개 |
| 11 | 우선 제외할 목록 | 제외 이유 포함 |
| 12 | 권장 확보 순서 | 번호 목록과 "가장 중요한 결론" 한 문장 |
| — | 근거와 확인 상태 | 직접 문의·카탈로그 조회 여부, Aside 카드 확인일 범위 |

## C. 검수 체크리스트

| ID | 기준 | 등급(위반 시) |
|---|---|---|
| C-01 | B표의 절이 모두 있음 | Major |
| C-02 | A표의 모든 ID가 3절 또는 4절에 나오고, 빠진 항목은 사유가 있음 | Major |
| C-03 | `[설명서 확인]`·`[카탈로그 확인]` 표기 행은 모두 digest/카드 ID 근거가 있고, 카드의 근거 수준과 라벨이 맞음 | Critical |
| C-04 | 카드에 없는 컬럼·조건을 확인된 것처럼 쓰지 않음 | Critical |
| C-05 | 8절 공통 기간 계산이 맞음 | Critical |
| C-06 | 미래 시점 자료(예: 2026년 가입자 자료)를 과거 예측 입력으로 쓰지 않음 | Critical |
| C-07 | 합성 데이터(D-11)를 실측으로 해석하지 않음 | Critical |
| C-08 | 5·6절이 "확인된 보유"가 아닌 "문의 제안"으로 표기됨 | Major |
| C-09 | 개인 식별이 필요 없다는 원칙과 집계 우선 요청이 있음 | Major |
| C-10 | 카드와 목록 기간이 다르면 둘 다 적고 차이를 표시함 | Major |
| C-11 | 문서 01의 5절과 데이터명·기간이 일치함 | Major |
