# 복제 상권 방지 서비스: 제공 데이터 목록과 추가 수집 계획

작성일: 2026-10-07  
버전: v4
대상 아이디어: 여러 공실의 업종 조합·입점 순서를 설계하고 실제 입점 결과로 추천을 갱신하는 서비스

## 1. 문서 범위와 읽는 방법

사용자가 처음 첨부한 데이터 목록 이미지 1~9를 기준으로, 이 아이디어에 직접 사용하거나 조건부로 보완할 수 있는 데이터를 모았다. 중복 첨부된 대구 데이터 목록은 한 번만 반영했다.

- **[목록 확인]:** 첨부 이미지에서 데이터명·기간만 확인한 자료다. 현재 신청 가능 여부나 상세 필드까지 확인됐다는 뜻은 아니다.
- **[카탈로그 확인]:** 수집 카드의 근거 수준이 `카탈로그`이며 공개 카탈로그·소개 페이지에서 이름·기간·개요를 확인한 자료다.
- **[설명서 확인]:** 수집 카드의 근거 수준이 `설명서`이며 데이터 설명서에서 항목·조건까지 확인한 자료다.
- **[추가 문의]:** 기존 목록만으로 보유·제공 여부를 알 수 없어 안심구역에 확인할 자료다.
- **[외부 확보]:** 안심구역 제공만으로 충족하기 어려워 운영사·점포·현장 조사 등으로 확보할 자료다.
- **[가설]:** 데이터로 검증해야 하며 아직 효과나 관계가 확인되지 않은 주장이다.

v4 시점 3·4절은 모두 **[목록 확인]** 수준이며, D-01·D-03·D-04는 제공기관 소개에서 데이터 유형만 참고로 확인했다. 해당 카드도 안심구역 제공 데이터와 같은지, 데이터 이름·기간·공간·시간 단위와 상세 컬럼을 확인하지 못했다. D-02·D-05~D-10은 재수집이 필요하다. 모든 데이터는 개인 식별 정보 없이 목적에 필요한 집계 형태로 우선 요청한다.

표의 ‘필요 항목’은 우리가 요청해야 할 항목이며 실제 제공 컬럼이라고 단정하지 않는다. 기관 간 연결, 이용 목적, 공간 정밀도와 반출 조건 역시 별도 확인이 필요하다. 이 문서는 원자료를 수집한 결과가 아니라 **데이터 확보를 위한 명세서**다.

## 2. 먼저 확보할 핵심 묶음

| 우선순위 | 묶음 | 답하려는 질문 |
|---|---|---|
| 1 | 전체 점포 현황·개폐업/입점 이력 | 지금 어떤 공급이 있고 언제 바뀌었는가? |
| 1 | 지역·업종·기간별 매출 및 거래 건수 | 실제 소비가 어떤 업종과 시간에 발생하는가? |
| 1 | 공실 위치·면적·층수·임대료·시설 조건 | 현실적으로 어느 공간에 무엇을 넣을 수 있는가? |
| 1 | 시간대별 유동인구 | 누가 언제 지역을 이용하는가? |
| 2 | 가격대·메뉴·영업시간·품목별 POS | 같은 업종 안에서도 같은 수요를 겨냥하는가? |
| 2 | 입점 예정·계약 진행 상태 | 여러 공실에 같은 업종이 동시에 추천되는 문제를 조정할 수 있는가? |
| 2 | 입점 전후 참여 점포 운영 결과 | 추천 이후 무엇이 달라졌는가? |

현재 목록에서는 매출·유동인구·일부 점포 자료를 찾을 수 있다. 그러나 **전체 독립 점포, 정확한 입점 이력, 실제 공실 조건, 입점 예정 정보**는 확보 여부가 불명확하다. 이 네 가지가 개별 공실 추천의 핵심 관문이다.

## 5. 안심구역에 추가로 요청하면 좋은 데이터

**다음 표는 보유가 확인된 목록이 아니다.** ‘추가로 제공 가능한지’ 문의할 요청 명세다. 동일 종류 자료라도 표본·시기·지역이 기존 데이터와 맞아야 한다.

| 우선순위 | 추가 요청 데이터 | 원하는 항목·형태 | 활용 목적 |
|---|---|---|---|
| 최우선 | [추가 문의] 독립 점포 포함 전체 점포의 시점별 현황 | 지속 가능한 점포 ID, 좌표/지역, 업종, 개업·폐업·이전·업종변경 일자 | 공급 변화와 경쟁 점포 누락 보완 |
| 최우선 | [추가 문의] 점포별 또는 작은 지역별 매출·거래 건수 이력 | 점포/지역 ID, 업종, 월 또는 주, 매출·건수, 표본 변경 표시 | 입점 전후 분석과 신규·기존 점포 변화 구분 |
| 최우선 | [추가 문의] 동일 기간·지역의 유동인구 보완본 | 2025년 자료 또는 선정한 분석 기간과 일치하는 자료 | 2025년 카드 자료와 동시점 분석 |
| 높음 | [추가 문의] 고객 출발 지역–소비 지역 집계 | 거주/근무지 등 기준이 명확한 지역, 소비지역, 업종, 기간별 집계 | 역외 소비와 생활권 분석 |

| 높음 | [추가 문의] 가격·메뉴·영업시간 변화 이력 | 점포 ID, 적용 기간, 메뉴/품목군, 가격대, 영업시간 | 같은 업종 안의 실질적 경쟁 구분 |
| 높음 | [추가 문의] 방문·체류 및 통행 목적 관련 집계 | 방문/통과 추정의 정의, 체류 구간, 기간·지역 | 단순 통과 인구와 이용 가능 인구 구분 |
| 높음 | [추가 문의] 할인·행사·휴업·공사 기록 | 적용 지역·점포, 시작·종료일, 행사 유형 | 입점 효과와 일시적 외부 요인 구분 |
| 보통 | [추가 문의] 상가 공실·임대료·건물 용도·층수 | 실제 조사 기준일, 주소/건물키, 공실 정의, 임대료 조건 | 안심구역 보유 가능성이 낮아 `보통`; 핵심 확보 경로는 7절 **[외부 확보]**. 공실별 실행 가능성 판단 |

점포 간 연속 이용은 한 점포가 다른 점포 매출을 증가시켰다는 인과 증거가 아니다. 카드 자료의 ‘소비 지역’만으로 고객 거주지를 알 수 없으며, 거주지 추정 제공 여부와 정의를 별도로 확인한다. 개인별 경로 원본 대신 목적에 필요한 집계 형태를 우선 문의한다.

## 6. 어떤 안심구역에 무엇을 문의할까?

첨부된 안심구역 소개의 제공 분야를 바탕으로 한 **문의 경로 제안**이다. 각 추가 데이터의 실제 보유를 확인한 결과는 아니다.

| 문의 후보 | 첨부 소개의 제공 분야 | 이번 아이디어에서 문의할 내용 |
|---|---|---|
| 한국데이터산업진흥원 데이터안심구역 | 통신·금융·연구·의료 등(목록 기준; 공식 페이지 재확인 필요) | 카드·POS·통신 상세 설명서, 전체 점포 이력, 공통 기간 자료, 결합 가능 수준 (Q-01: 보유 목록·문의처 미확인) |
| 경북대학교 첨단정보통신융합산업기술원 대구데이터안심구역 | 교통·금융·기업·에너지 | 대구로 주문·가맹점의 상세 항목, 대구 상권·기업·입점 이력 보완 가능 여부 |
| 한국국토정보공사 공간정보 안심구역 | 항공사진·위성영상·전자지도 등 공간정보 | 건물·도로·출입구·용도·층수 관련 레이어 보유 여부, 연결키 |
| 한국지능정보사회진흥원 K-ICT 빅데이터센터 | 마케팅·시장 분석·제품 판매·동향 분석 | 업종별 소비, 산업 생태계, 가격·품목·온라인 소비 자료의 지역·기간 범위 |

| 한국도로공사 국토교통 데이터안심구역 | 도로·버스·철도·시설·안전 | 선정 지역의 대중교통 접근성·이용 집계 제공 가능 여부 |

한국전력공사의 점포·건물 전력 자료는 휴업·가동의 간접 지표로 검토할 수 있으나, 업종·계량기·건물의 연결과 해석 문제가 있어 초기 수집 우선순위에서 제외한다. 의료·농업 안심구역은 이번 일반 상권 조합 설계의 주된 문의처로 잡지 않는다.

7. 메뉴·품목·영업시간·할인·휴업 이력이 있는가?

## 11. 이번 아이디어에서 우선 제외할 목록

교통사고, 폐기물·재활용·수질, 의료영상, 스마트팜·축산 경락가격, 수소충전소 설비 운전, 해안침식·해수욕장 지형, 고속도로 졸음쉼터 센서 등은 일반적인 공실 업종 조합을 결정하는 직접 자료가 아니다. 특정 관광상권·농산물 판매·충전소 상권 등으로 주제를 바꾸지 않는 한 수집하지 않는다.

경상북도개발공사의 토지 수납·약정·계약·계약자·거래처·주택 분양 자료도 실제 상가 공실과 임대 조건을 대체하지 못한다. 전국 전기차 충전전력량은 충전 대기 소비를 다루는 별도 주제로 좁힐 때 검토할 수 있으나 초기 모델에서는 제외한다.

## 12. 권장 확보 순서

1. 2024 일반 상권·2023 POS·2025 카드·대구 음식점 중 실제 지역과 항목이 맞는 한 분석안을 선택한다.
2. 핵심 매출·점포·유동인구의 설명서와 표본 범위를 확보한다.
3. 전체 점포 이력과 공실 조건의 확보 가능성을 확인한다.
4. 입점 예정 정보를 관리할 운영 주체를 정한다.
5. 부족한 기간·시간대·가격대·입점 이력만 추가 요청한다.
6. 과거 입점 전후 평가와 소규모 현장 검증을 구분해 진행한다.

**가장 중요한 결론:** 목록상 기간 기준으로 상권 진단 착수를 검토할 수 있으나, 공간 단위와 항목은 설명서 확인 전이다. 여러 실제 공실의 업종 조합과 입점 순서를 설계하려면 전체 점포 이력·공실 조건·입점 예정·운영 결과가 추가로 필요하다.

## 근거와 확인 상태

근거: 사용자가 처음 첨부한 데이터 제공 목록 이미지 및 안심구역 소개 이미지, 기존 복제 상권 방지 사업 기획안. 공식 카탈로그(dsz.kdata.or.kr)는 열람을 시도했으나 HTTP 503으로 조회하지 못했다(카드 D-01·Q-01). 제공기관에 직접 문의하지는 않았다. 목록상 보유 기간, 추가 확보 제안, 실제 수집 완료 여부를 구분해 사용한다.

수집 카드: B1 11건(D-01~D-10, Q-01), 확인일 2026-10-10. 제공기관 소개 수준에서 일부 확인된 D-01·D-03·D-04를 제외하면 공식 상세 페이지를 찾지 못했거나 문의처 확인이 남아 있다.
