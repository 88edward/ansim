# 복제 상권 방지: AI 기반 상권 조합 설계 서비스

작성일: 2026-10-04  
버전: v1  
용도: 데이터안심구역 경진대회 사업 아이디어 구체화  
상태: 설계안. 데이터 상세 항목 및 효과 검증 전.

## 1. 사업 개요

**여러 공실에 들어갈 업종과 입점 순서를 함께 설계하고, 입점 이후 결과에 따라 다시 조정하는 서비스**다.

인기 업종을 개별 점포마다 반복 추천하는 대신, 기존 점포가 충족하는 수요와 아직 충족되지 않은 수요를 구분한다. 신규 입점이 주변 점포에 미칠 영향을 비교하고, 입점 예정 정보와 실제 운영 결과를 다음 추천에 반영한다.

출품 설명:

> 여러 공실에 같은 인기 업종을 반복 추천하는 문제를 줄이기 위해, 지역 수요와 기존·예정 점포를 함께 분석하여 업종 조합과 입점 순서를 설계하고, 실제 입점 결과로 다음 추천을 갱신하는 AI 서비스.

같은 업종이 많다는 이유만으로 부정적으로 판단하지 않는다. 유사 업종의 집적이 방문 수요를 만들 수도 있다. 줄이려는 대상은 **같은 시간대·가격대·고객 목적을 겨냥해 기존 소비만 나눠 갖는 입점**이다. 같은 음식점이라도 직장인 점심, 가족 저녁, 심야 포장 수요를 나누어 충족할 수 있다.

## 2. 고객과 사업 모델

초기 고객은 여러 공실의 입점을 조정할 수 있는 상가 운영사·건물주·상권 관리 조직으로 설정한다. 개별 창업자 대상 추천만으로는 여러 이용자가 같은 인기 업종을 선택하는 문제를 조정하기 어렵다.

| 구분 | 내용 |
|---|---|
| 고객의 문제 | 공실을 채워야 하지만 인기 업종만 유치하면 기존 점포와 경쟁이 심해지고 상권 구성이 비슷해짐 |
| 서비스의 결정 | 어느 점포에 어떤 업종·가격대·영업시간의 가게를 어떤 순서로 유치할지 |
| 제공 결과 | 공실별 입점 후보, 전체 업종 조합 3안, 입점 순서, 추천 근거와 불확실성 |
| 입점 후 서비스 | 실제 매출·시간대별 이용 변화로 남은 공실의 추천 갱신 |
| 수익 모델 제안 | 초기 상권 진단·입점 구성 설계비 + 입점 이후 모니터링 구독료 |

실제 창업자의 참여, 계약 체결, 입점 결정은 추천과 별개다. 초기에는 한 운영사가 관리하는 상가나 한 블록에 집중한다.

## 3. 사용 사례

다음은 효과가 검증된 사례가 아닌 가상의 서비스 설명이다.

오피스와 주거지가 섞인 블록에 공실 3개가 있다고 가정한다.

- A점포: 대로변 1층, 작은 면적, 조리시설 제한.
- B점포: 1층, 주방 설치 가능, 상대적으로 높은 임대료.
- C점포: 안쪽 골목, 낮은 임대료, 저녁 유동인구 불확실.

서비스는 업종부터 확정하지 않고 다음 가설을 검토한다.

> 점심 식사 수요는 이미 충분히 충족되지만, 퇴근 이후 간편식 구매 수요는 지역 밖으로 빠져나가는가?

| 시나리오 | 구성 | 확인할 점 |
|---|---|---|
| 개별 매출 우선 | 각 공실에 예상 매출이 가장 높은 업종 배치 | 세 곳이 같은 고객을 나눠 갖는가? |
| 상권 조합 우선 | 아침·점심·퇴근 후 수요를 나눠 담당하도록 배치 | 기존 점포와 신규 점포가 함께 유지될 수 있는가? |
| 순차 입점 | 한 곳을 먼저 열고 나머지는 결과 확인 후 결정 | 공실 유지 비용을 감수할 만큼 불확실성이 줄어드는가? |

간편식 수요가 부족한지는 데이터로 검증할 가설이다. 유동인구가 많고 매출이 적다는 사실만으로 구매 수요가 있다고 판단하지 않는다.

## 4. 서비스 흐름과 AI 활용

| 단계 | 이용자와 서비스가 하는 일 | AI 및 분석의 역할 | 결과물 |
|---|---|---|---|
| ① 공실 등록 | 위치·면적·층수·임대료·시설·입점 가능 시기 입력 | 문서나 설명에서 조건 추출 보조. 최종 조건은 운영자가 확인 | 점포별 입점 가능 업종 |
| ② 지역 수요 진단 | 시간대별 사람·소비·기존 점포 분포 분석 | 비슷한 지역을 찾아 비교하고 업종별 수요 패턴 추정 | 충족된 수요·부족 가능 수요 지도 |
| ③ 입점 영향 추정 | 후보 업종 입점 시 신규·기존 점포 변화 비교 | 과거 입점 사례에서 매출 변화와 경쟁 관계 학습 | 후보별 예상 범위와 경쟁 위험 |
| ④ 전체 조합 설계 | 여러 공실의 업종·운영시간·입점 순서 선택 | AI 예측값을 활용해 수리 최적화로 조합 비교 | 실행 가능한 조합 3안 |
| ⑤ 소규모 검증 | 팝업·예약 판매·단기 운영 등으로 수요 확인 | 예상과 실제 차이를 반영해 예측 갱신 | 정식 입점·수정·보류 판단 |
| ⑥ 입점 후 재설계 | 신규 매출뿐 아니라 주변 점포와 이용시간 변화 확인 | 수요 변화 탐지, 남은 공실의 후보 재평가 | 다음 입점 추천 |

### AI 구현 방향

AI의 중심은 **수요 예측과 입점 영향 추정**이다. 언어모델은 조건 입력과 결과 설명을 돕는 역할로 둔다.

- **수요 예측:** 지역·업종·시간대별 매출을 예측하는 표 형태 데이터용 모델부터 시작한다.
- **유사 상권 탐색:** 인구 구성·시간대 이용·업종 비중이 비슷한 지역을 묶어 비교한다.
- **입점 영향 분석:** 신규 입점 지역과 변화 이전의 특성이 비슷한 비교 지역을 대조한다. 단순한 동반 상승을 상생 효과로 판단하지 않는다.
- **조합 선택:** 면적·시설·예산 제약 아래 예상 수요, 경쟁 부담, 공실 유지 비용을 함께 비교한다. 수리 최적화와 AI 예측의 역할을 구분한다.

개별 소비자의 가게 간 이동 기록이 없다면 특정 가게 방문자가 다른 가게로 이동한다는 소비 동선을 제시하지 않는다. 관측 자료만으로 입점의 인과 효과를 확정할 수 없으며, 비교 분석의 가정과 불확실성을 표시한다.

### 데이터 사용 시 핵심 조건

1. **프랜차이즈 자료만으로 전체 경쟁 점포를 파악하지 않는다.** 독립 점포가 빠지므로 전체 점포 목록을 보완한다.
2. 나이스 상권 매출과 SKT 유동인구의 공통 분석 기간은 **2024년 1~10월**이다.
3. 2023년 POS와 2025년 카드 자료를 같은 시점의 관측처럼 합치지 않는다. 과거 패턴 참고와 별도 연도 분석을 구분한다.
4. 기관 간 점포 식별자가 같다고 가정하지 않는다. 공통 공간·업종·기간으로 집계해 비교할 수 있는지 확인한다.
5. 점포별 자료가 없으면 건물·개별 점포 수준 효과를 주장하지 않고 상권 단위 분석으로 범위를 조정한다.

## 7. 핵심 차별화: 입점 예정까지 반영하는 추천

현재 카페가 부족해 세 공실 모두 카페를 추천받았더라도, A점포가 카페 입점을 확정하면 B·C의 추천을 다시 계산한다.

**현재 상권 분석 → 입점 예정 반영 → 첫 입점 결과 관측 → 다음 입점 재설계**

추천 서비스 자체가 비슷한 가게를 반복적으로 만들어내는 문제를 줄이는 것이 목적이다. 참여 운영사가 관리하는 범위에서 입점 예정 정보를 확보하고, 이후 실제 성과를 반영한다.

추천 결과는 단일 정답보다 다음과 같이 제시한다.

- 현재 정보에서 우선 검토할 조합.
- 수요가 예상보다 낮을 때 부담이 작은 조합.
- 먼저 소규모 검증한 뒤 나머지 입점을 결정하는 조합.

## 8. 배달 효율화 아이디어와의 결합

음식점 후보에 대해 다음을 추가 평가할 수 있다.

- 기존 음식점과 같은 배달 목적지·시간대에 주문이 몰리는가?
- 새 음식점이 부족한 메뉴 수요를 채우는가?
- 주문 증가에 비해 추가 라이더·대기 부담이 얼마나 생기는가?

대구로 주문·배달·가맹점 자료에 주문 위치·시간·업종 등 필요한 항목이 제공되는 경우 확장한다. 라이더 이동·대기 기록이 없으면 해당 효과는 가정을 명시한 시뮬레이션으로 제한한다.

초기 작품은 상권 조합 설계에 집중하고, 배달 운영은 확장 기능으로 둔다.

## 9. 공모전 시제품 범위

**한 지역, 공실 3~5개, 후보 업종 5~8개**로 범위를 좁힌다.

| 화면 | 주요 기능 |
|---|---|
| 상권 진단 지도 | 시간대별 소비·유동인구·경쟁 업종 표시 |
| 공실 조합 비교 | 개별 추천 방식과 전체 조합 방식의 차이 표시 |
| 입점 계획 갱신 | 한 점포의 입점 확정 후 나머지 추천 변화 시연 |
| 검증 화면 | 실제 관측값, 모델 추정값, 시뮬레이션 결과 구분 |

### 검증 계획

- 수요 예측 정확도를 과거 시점 이후의 관측값으로 평가한다.
- 시설·면적·예산 등 실행 조건을 충족한 추천 비율을 확인한다.
- 개별 예상 매출 우선 추천과 전체 조합 추천을 동일 조건에서 비교한다.
- 신규 점포뿐 아니라 기존 점포의 변화와 공실 유지 부담도 평가한다.
- 업종 다양성 증가만으로 성공을 판단하지 않는다.
- 실제 입점 실험이 없다면 매출 증가나 폐업 감소를 달성했다고 주장하지 않는다. 시뮬레이션 결과와 실제 효과를 구분한다.

## 10. 우선 실행할 일

1. 제공 데이터 설명서에서 점포·업종·위치·시간·입점 이력의 제공 수준을 확인한다.
2. 공통 기간과 지역이 확보되는 데이터 조합을 선택한다.
3. 여러 공실 정보를 제공할 수 있는 운영 주체를 찾는다.
4. 공실 조건과 전체 경쟁 점포 목록을 확보한다.
5. 단순 수요 예측과 개별 추천을 기준선으로 구현한다.
6. 입점 예정 반영 및 전체 조합 비교 기능을 추가한다.
7. 과거 자료 평가와 가능한 소규모 현장 검증으로 추천을 갱신한다.

## 자료 근거와 한계

기존 「데이터안심구역_6가지_아이디어_구체화.md」의 2번 아이디어, 사용자가 첨부한 제공 데이터 목록, 후속 대화에서 구체화한 설계를 바탕으로 작성했다. 실제 데이터 열람·분석, 시장성 검증, 추천 효과 실증은 수행하지 않았다. 수익 모델과 구현 범위는 제안이며, 구체적인 데이터 이용·결합·결과 반출 가능 여부는 별도로 확인해야 한다.
