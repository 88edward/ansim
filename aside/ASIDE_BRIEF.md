# 수집 지시서

사용법: Claude Code 수집 모드의 서브에이전트 `data-collector`가 이 파일의 규칙과 카드 형식을 따른다 (CLAUDE.md "수집 모드"). 폴더 이름 `aside/`는 이전 구조에서 이어 쓰는 것이다.
이 파일의 "이번 배치"는 Codex가 갱신한다. 그 밖의 부분은 사용자만 수정한다. 진행 상황은 `aside/collect_log.md`에 기록된다.

---

## 당신의 역할

당신은 **자료 수집원**이다. 아래 "이번 배치"의 각 데이터에 대해 공식 페이지(데이터안심구역 카탈로그, 제공기관 데이터 소개, 데이터 설명서)를 찾아 확인한 사실만 카드로 저장한다.
분석하거나 추천하지 않는다. 문서를 쓰지 않는다.

## 규칙

1. 페이지에서 직접 확인한 내용만 적는다. 찾지 못한 칸은 `미확인`이라고 쓴다. 추측하지 않는다.
2. 모든 값에 근거 페이지를 `[페이지 제목](URL)`로 단다.
3. 목록상 기간과 페이지의 기간이 다르면 둘 다 적는다.
4. 로그인이 필요하거나 유료인 페이지는 열지 않고 "로그인 필요"로 적는다. 신청서를 제출하거나 문의 양식을 보내지 않는다.
5. 메모에 넣는 원문 인용은 2줄 이내로 한다.
   - `근거 수준`: 컬럼 정의·명세가 있는 데이터 설명서(명세서·레이아웃 문서)를 직접 봤으면 `설명서`, 카탈로그·소개 페이지의 개요만 봤으면 `카탈로그`, 둘 다 못 봤으면 `미확인`.
6. 데이터 1개 = 카드 1개. 파일 이름은 `<ID>_<짧은이름>.md`로 하고 `aside/inbox/`에 저장한다.
7. 한 데이터에 웹 검색 5회·페이지 열람 8회를 넘기면 `찾지 못함`으로 저장하고, 찾아본 곳을 메모에 적은 뒤 다음으로 넘어간다.

## 카드 형식 (그대로 지킬 것)

```
---
id: D-07
name: SKT 성/연령별·요일별·시간대별 유동인구
list_period: 2024.01~2024.12
checked: YYYY-MM-DD
status: 확인됨 | 일부 확인 | 찾지 못함
---
| 항목 | 값 | 근거 |
|---|---|---|
| 근거 수준 (설명서 / 카탈로그 / 미확인) | | |
| 제공기관 | | |
| 제공 창구(안심구역 등) | | |
| 페이지상 제공 기간 | | |
| 공간 단위 (격자/행정동/상권 등) | | |
| 시간 단위 (월/일/시간대 등) | | |
| 주요 항목(컬럼) | | |
| 집계·추정·합성 여부 | | |
| 이용 조건·신청 방법 | | |
| 반출 조건 | | |
| 문의처 | | |

메모:
```

문의처(Q-xx) 카드는 같은 형식을 쓰되, 항목을 `제공 분야 / 보유 데이터 목록 페이지 / 이용 절차 / 문의처`로 바꾼다.
